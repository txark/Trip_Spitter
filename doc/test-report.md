## 3) สิ่งที่ยังไม่ได้ทดสอบ

- **หน้าเว็บ (Frontend) ไม่มีการทดสอบอัตโนมัติ** ทดสอบด้วยมือผ่านเบราว์เซอร์เท่านั้น
- **ไม่ได้วัด code coverage** ด้วยเครื่องมือ (เช่น JaCoCo) ตัวเลขข้างบนเป็นจำนวนเคสที่ผ่าน ไม่ใช่เปอร์เซ็นต์โค้ดที่ถูกทดสอบ
- **Controller และ Repository ไม่มี unit test ของตัวเอง** ถูกทดสอบผ่านชุด API Test (ยิงจริงผ่านทุกชั้น) แทน
- **ไม่มี load test** ทดสอบความถูกต้องเมื่อใช้งานพร้อมกัน (concurrency) แต่ไม่ได้วัดประสิทธิภาพเมื่อผู้ใช้จำนวนมาก
- **ทดสอบบนเครื่องจริงบน Cloud (Render + Neon)** ทำเฉพาะการตรวจว่าหน้าเว็บ Swagger และ API ตอบ ไม่ได้รันชุด API Test ทั้งชุดกับฐานข้อมูลจริง เพื่อไม่ให้ข้อมูลทดสอบปนกับข้อมูลใช้งาน
