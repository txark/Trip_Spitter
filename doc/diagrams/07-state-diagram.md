# State Diagram

Entity ที่มีสถานะในระบบ 3 ตัว: **โหวต (Poll)**, **ส่วนแบ่งของบิล (ExpenseSplit)** และ **รหัสกู้คืน (Recovery code)**

## 1) โหวต (`polls.status`)

```mermaid
stateDiagram-v2
    [*] --> ACTIVE : สร้างโหวต
    ACTIVE --> ACTIVE : ลงคะแนน, เปลี่ยนตัวเลือก, ยกเลิกคะแนน, เพิ่มตัวเลือก
    ACTIVE --> CLOSED : ผู้สร้างโหวตกดปิด (เฉพาะผู้สร้าง)
    ACTIVE --> CLOSED : ถึงเวลาปิดอัตโนมัติ (closes_at)
    ACTIVE --> [*] : ผู้สร้างลบโหวต
    CLOSED --> [*] : ผู้สร้างลบโหวต
    note right of CLOSED
        ปิดแล้วลงคะแนนไม่ได้
        (400 ถูกปิดรับคะแนนแล้ว)
    end note
```

## 2) ส่วนแบ่งของบิล (`expense_splits`)

สถานะคำนวณจากฟิลด์ `is_paid` และ `paid_amount` ของแต่ละส่วนแบ่ง

```mermaid
stateDiagram-v2
    [*] --> ยังไม่จ่าย : สร้างบิล (paid_amount ว่าง)
    ยังไม่จ่าย --> จ่ายบางส่วน : บันทึกรับเงินคืนไม่ครบยอด
    จ่ายบางส่วน --> จ่ายบางส่วน : รับเงินเพิ่มแต่ยังไม่ครบ
    จ่ายบางส่วน --> จ่ายครบ : รับเงินครบยอด (is_paid = true)
    ยังไม่จ่าย --> จ่ายครบ : รับเงินครบยอดในครั้งเดียว หรือผู้จ่ายกดยืนยัน
    จ่ายบางส่วน --> ยังไม่จ่าย : ยกเลิกการรับเงิน (ผู้รับเท่านั้น)
    จ่ายครบ --> จ่ายบางส่วน : ยกเลิกการรับเงินบางรายการ
    จ่ายครบ --> ยังไม่จ่าย : ยกเลิกการรับเงินทั้งหมด
    note right of จ่ายครบ
        บิลที่มีการจ่ายคืนแล้ว
        แก้หรือลบไม่ได้ (409)
    end note
```

## 3) รหัสกู้คืนของผู้ใช้ (`users.recovery_hash`, `recovery_expires_at`)

```mermaid
stateDiagram-v2
    [*] --> ไม่มีรหัส
    ไม่มีรหัส --> ใช้งานได้ : ผู้สร้างทริปออกรหัส 6 หลัก (หมดอายุใน 30 นาที)
    ใช้งานได้ --> ใช้งานได้ : ออกรหัสใหม่ (ทับรหัสเดิม)
    ใช้งานได้ --> ไม่มีรหัส : เพื่อนกรอกรหัสถูกต้อง (ออก token ใหม่ และล้างรหัสทิ้งทันที)
    ใช้งานได้ --> หมดอายุ : เกิน 30 นาที
    หมดอายุ --> ใช้งานได้ : ออกรหัสใหม่
```
